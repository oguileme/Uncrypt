# Uncrypt

Plataforma de aprendizagem e prática de criptografia, do básico às cifras clássicas até modelos modernos. Os usuários evoluem seus conhecimentos através de desafios práticos e gamificados.

## Sobre o projeto

O Uncrypt é um sistema onde o usuário resolve desafios de decifração de diferentes tipos de criptografia (César, Vigenère, Playfair, entre outras), com progressão de dificuldade, dicas, histórico de tentativas e um sistema de gamificação (conquistas, níveis, sequências).

## Funcionalidades planejadas

- Cadastro e login de usuários
- Geração de desafios a partir de cifras pré-definidas no sistema
- Verificação automática de respostas
- Sistema de dicas
- Histórico e reforço de desafios já resolvidos
- Métricas de desempenho (tempo de resolução, acertos/erros, desempenho por tipo de cifra)
- Sistema de gamificação: conquistas, níveis, recompensas e sequência de dias (streak)

## Tecnologias

- **Backend:** Laravel
- **Banco de dados:** PostgreSQL
